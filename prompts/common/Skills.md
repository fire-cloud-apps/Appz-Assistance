# 1. Technology Stack

### Frontend

| Technology  | Purpose                 |
| ----------- | ----------------------- |
| React       | UI framework            |
| Mantine UI  | Component library       |
| React Query | Data fetching & caching |
| Zustand     | Client state management |
| Dexie       | IndexedDB wrapper       |
| Day.js      | Date utilities          |
| UUID        | Unique ID generation    |
