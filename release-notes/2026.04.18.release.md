# Release Notes - 2026.04.18
**Version:** 1.7.55
**Build Date:** 2026.04.18-13
**Module:** Finance Goals - Goals & SIP

---

## Summary
Improved the layout of Add/Edit modals for Goals and SIPs by placing the Name and Icon selection fields on the same row. This provides a more compact and efficient form design.

---

## New Features
### 1. Improved Modal Layout (Goals & SIPs)
- **Compact Field Arrangement**: Goal/SIP Name and Icon selection are now aligned horizontally in a single row.
- **Optimized Space**: The name field is given more prominence (`flex: 3`), while the icon picker has a minimum width of `250px` (`flex: 1`) to provide more space for searching icons.
- **Consistent UX**: Applied this layout improvement across both `GoalModal` and `SIPModal` for a unified experience in the Finance Goals module.

### 2. Enhanced IconPicker Component
- Added support for custom `style` props in the `IconPicker` component to allow flexible layout integration.

### 3. Goal Icon Support (Previous)
- Added `icon` property to `FinancialGoal` entity and data models.
- Integrated `IconPicker` in `GoalModal` for adding and editing goal icons.
- **GoalCard Visuals**:
  - Small icon displayed next to the goal title in the header.
  - Large background watermark icon (100px, 0.15 opacity) in the bottom-right corner.
- Ensured consistent visual styling between SIP and Goal cards.

### 4. Improved SIP Card Layout (Previous)
- Moved the **Active/InActive Badge** from the top header to the **Bottom-Left** corner of the card.
- Moved the background icon from top-left to **Bottom-Right** for better visual balance and to avoid overlapping with primary text.
- Increased background icon size to **100px** and adjusted opacity to **0.15**.
