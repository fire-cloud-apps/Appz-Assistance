## Summary

This release fixes critical calculation bugs in the Goals module, improves the user experience for Required Monthly Investment display, and resolves a UI issue where goal cards were expanding together.

---

## Bug Fixes

### 1. Required Monthly Investment Calculation (GoalModal.tsx)
- **Issue:** The calculation was treating every goal as a fresh investment from zero, completely ignoring existing principal (currentAmount + portfolioValue)
- **Root Cause:** Formula was calculating `PMT = Target * r / ((1+r)^n - 1)` instead of accounting for existing principal growth
- **Fix:** Updated calculation to:
  - Calculate future value of existing principal: `Principal * (1+r)^n`
  - Determine remaining gap: `Target - FutureValueOfPrincipal`
  - Calculate required monthly investment: `RemainingGap / AnnuityFactor`
- **Impact:** Now shows accurate, lower values when existing investments are present

### 2. Invalid Time Value Error
- **Issue:** "Unexpected Application Error! Invalid time value" when entering Target Amount
- **Root Cause:** `estimateMonthsToTarget` method calling `.toISOString()` on invalid dayjs objects without proper validation
- **Fix:** 
  - Added fallback date initialization
  - Wrapped `.toISOString()` calls in try-catch blocks
  - Added validation to check date validity before conversion
  - Protected `calculateProjection` method with error handling

### 3. Goal Cards Expanding Together
- **Issue:** Clicking "Show Details" on one goal would expand all goals simultaneously
- **Root Cause:** Shared state (`Set<string>`) in parent component causing synchronized re-renders
- **Fix:** 
  - Extracted `GoalCard` component with isolated local state
  - Each card now manages its own `isExpanded` state independently
  - Improved component architecture following React best practices
- **Impact:** Each goal now expands/collapses independently

## Enhancements

### 1. Simplified Required Monthly Investment Display
- **Removed:** Multiple growth rate options display (10%, 12%, 15%, 18%, 20%)
- **Removed:** Manual "Calculate" button
- **Added:** Automatic calculation based on selected growth rate only
- **Result:** Cleaner, more intuitive UX - calculations happen automatically

### 2. Currency Display Format
- **Before:** `To achieve target ₹50,000,000 by Apr 2040 at 12% p.a.`
- **After:** `To achieve target ₹5.0C(₹50,000,000) by Apr 2040 at 12% p.a.`
- **Implementation:** Created `formatIndianCurrency` helper function
  - Crores (≥ 10,000,000): `₹5.0C`
  - Lakhs (≥ 100,000): `₹25.0L`
  - Thousands (≥ 1,000): `₹5.0K`
  - Shows short format first, full format in parentheses

### 3. Improved Empty State Display
- When existing principal already covers the target, shows "✓ Already Covered" in green instead of "₹0/month"
