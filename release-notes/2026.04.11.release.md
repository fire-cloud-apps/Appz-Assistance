# Release Notes - 2026.04.11

**Version:** 1.7.17  
**Build Date:** 2026.04.11-01  
**Module:** Finance Goals

---

## Summary

This release enhances the Finance Goals module with support for multiple investors and portfolios per goal, making the goal tracking more flexible and realistic for joint investment scenarios.

---

## Features & Enhancements

### 1. **Goals Screen - Multi-Investor Support**
- **Feature:** Multiple investors can now contribute to a single goal
- **New Fields:**
  - `investorIds: string[]` - Array of investor IDs (replaces single `investorId`)
  - `portfolioIds: string[]` - Array of portfolio IDs (mandatory)
  - `currentAmount: number` - Manual current amount collected
  - `sipIds: string[]` - SIPs now optional (was mandatory)
- **Files Changed:**
  - `FinancialGoal.ts` (entity) - Added new fields
  - `FinancialGoal.ts` (model) - Added new fields
  - `validators.ts` - Updated schema

### 2. **Goals Screen - Multi-Portfolio Support**
- **Feature:** Multiple portfolios can be linked to a goal
- **Mandatory:** At least one portfolio is required per goal
- **Portfolio Value:** Automatically calculated from linked portfolios
- **Files Changed:**
  - `GoalModal.tsx` - Multi-select for investors and portfolios
  - `GoalsList.tsx` - Display investor names and portfolio values

### 3. **Goals Screen - Current Amount Input**
- **Feature:** Users can now manually input current amount collected
- **Display:** Shows portfolio value + current amount as total "Current"
- **Validation:** Non-negative number (allows 0)
- **Files Changed:**
  - `GoalModal.tsx` - Added currentAmount NumberInput
  - `GoalsList.tsx` - Shows combined current value

### 4. **Goals Screen - SIP as Optional**
- **Feature:** SIPs are now optional for goals
- **Rationale:** Investor may have inactive or no SIPs
- **Portfolio:** Remains mandatory
- **Files Changed:**
  - `validators.ts` - sipIds is no longer required
  - `GoalModal.tsx` - SIP selection is optional
  - `GoalsList.tsx` - Handles empty sipIds gracefully

### 5. **Goals Screen - Enhanced UI**
- **Investor Badge:** Shows all investor names linked to goal
- **Portfolio Badge:** Shows count of linked portfolios
- **Portfolio Value Card:** Displays total portfolio value
- **Total Current:** Combines portfolio value + current amount
- **Null Safety:** Added defensive checks for undefined arrays

## Technical Changes

### Data Model Changes
```typescript
// Old Structure
interface FinancialGoal {
  id: string
  investorId: string      // single investor
  targetAmount: number
  sipIds: string[]        // mandatory
  // ...
}

// New Structure

  id: string
  investorIds: string[]  // multiple investors
  portfolioIds: string[] // mandatory
  currentAmount: number // new field
  sipIds: string[]        // now optional
  // ...
}
```

- Now uses portfolio values directly
- Includes currentAmount in calculations
- Handles empty/inactive SIPs gracefully
- **Files Changed:**
