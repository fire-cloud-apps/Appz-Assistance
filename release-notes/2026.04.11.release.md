# Release Notes - 2026.04.11

**Version:** 1.7.16  
**Build Date:** 2026.04.11  
**Module:** Finance Goals

---

## Summary

This release focuses on enhancing the Finance Goals module, specifically the SIP Management and Goals screens. Major improvements include adding card layout views, auto-generated SIP names, and simplifying goal creation to be SIP-centric.

---

## Features & Enhancements

### 1. **SIP Management - Portfolio Display Fix**
- **Issue:** Portfolio column was displaying unique IDs instead of meaningful names
- **Solution:** Updated to display "Portfolio Schema Name (Folio ID)" format
- **Files Changed:**
  - `SIPTable.tsx` - Updated display logic
  - `usePortfolio.ts` - Added `loadPortfoliosAll()` method
  - `useFinanceGoalStore.ts` - Added `loadPortfoliosAll()` and `resetPortfoliosState()` methods
  - `FinanceGoalSIPPage.tsx` - Fixed race condition with isolated portfolio loading
  - `FinanceGoalPortfolioPage.tsx` - Added state reset on mount

### 2. **SIP Management - Card Layout View**
- **Feature:** Added responsive card layout as an alternative to table view
- **Default View:** Card view is now the default
- **Toggle:** Added icon-based toggle between Table and Card views
- **Files Changed:**
  - `SIPCard.tsx` (new) - Card component with responsive grid (1-4 columns)
  - `SIPTable.tsx` - Existing table component
  - `FinanceGoalSIPPage.tsx` - Added view toggle with ActionIcon buttons
  - `components/index.ts` - Exported SIPCard

### 3. **SIP Management - Auto-Generated SIP Names**
- **Feature:** SIP names are now auto-generated during creation
- **Format:** `{AMC Name} ({Short Scheme Name}) - {Amount} - ({Start Date})`
- **Example:** `Nippon (Mid Cap Fund) - 2500 - (05-11-2025)`
- **Flexibility:** Users can override with custom names
- **Files Changed:**
  - `SIP.ts` (entity) - Added `name: string` field
  - `SIP.ts` (model) - Added `name: string` field
  - `validators.ts` - Updated `sipSchema` to include name
  - `SIPModal.tsx` - Added auto-generation logic and name input field
  - `SIPTable.tsx` - Added SIP Name as first column
  - `SIPCard.tsx` - SIP Name displayed as prominent card title

### 4. **Goals Screen - SIP-Centric Redesign**
- **Major Change:** Removed AMC and Portfolio selection from goals
- **Simplified Flow:** Goals now created using only Investor + SIPs
- **Removed Fields:**
  - `amcName` from FinancialGoal entity and model
  - `portfolioIds` from FinancialGoal entity and model
- **Files Changed:**
  - `FinancialGoal.ts` (entity & model) - Removed fields
  - `validators.ts` - Updated schema
  - `GoalModal.tsx` - Complete rebuild with SIP-only selection
  - `GoalsList.tsx` - Removed AMC badge, updated current value calculation
  - `FinanceGoalGoalsPage.tsx` - Removed portfolio dependencies
  - `FinanceGoalDashboardPage.tsx` - Updated GoalModal props
  - `CalculateGoalProgressUseCase.ts` - Now uses SIP repository
  - `ForecastGoalCompletionUseCase.ts` - Removed portfolio dependency
  - `useFinanceGoalDashboardData.ts` - Updated use case instantiation
  - `useGoalForecasts.ts` - Removed portfolio repository

### 5. **Goals Screen - Enhanced Calculations**
- **Total Monthly SIP Investment:** Auto-calculated when multiple SIPs selected
- **Growth Rate Selector:** SegmentedControl with 10%, 12%, 15%, 18%, 20% options
- **Investment Calculator:** Shows required monthly investment for all growth rates
- **Theme Support:** All colors now use Mantine CSS variables for dark/light mode
- **Files Changed:**
  - `GoalModal.tsx` - Added calculator components and theme-aware styling
  - `GoalsList.tsx` - Added SIP total display and growth rate badge

## Technical Improvements

### Race Condition Fixes
- Isolated portfolio loading in SIP page to prevent store conflicts
- Added `hasLoadedAllPortfolios` ref to prevent duplicate loads
- Implemented `resetPortfoliosState()` for clean page transitions

### Theme Compliance
- Replaced all hardcoded colors with Mantine CSS variables
- `var(--mantine-color-blue-light)` for backgrounds
- `var(--mantine-color-gray-light)` for secondary backgrounds
- Full dark/light theme support

### Code Quality
- Removed unused imports throughout the module
- Fixed TypeScript compilation errors
- Clean build with no warnings
