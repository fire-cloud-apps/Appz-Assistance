# Release Notes - 2026.04.05

## Version 1.7.13

### Features Implemented
- **Settings - Export/Import Finance Goals**: Added Finance Goals module to Export Data and Import Data sections in Settings screen
  - Export: Goals, Portfolios, SIPs, and Investors
  - Import: Restores all Finance Goals data from JSON export

- **Portfolio Pagination Fix**: Fixed pagination not working when switching between menus
  - Changed addPortfolio, updatePortfolio, removePortfolio to use paginated queries instead of loading all data
  - Removed loadAll() call that was causing full data load on menu switch
  - Now properly respects page size settings

## Version 1.7.12

### Features Implemented
- **Excel Portfolio Import**: Replaced JSON import with Excel (.xlsx) based import mechanism for CAS statements
  - Auto-detects "Portfolio Details" sheet
  - Extracts investor metadata (name, mobile, PAN) with masking
  - Filters zero-value portfolios (rejects if Invested Value, Current Value, or Units is 0)
  - Shows rejection count in import summary

- **Pagination**: Added pagination to Portfolio screen with configurable page sizes (5, 10, 25, 50)
  - Default page size: 5 (stored in user settings)
  - Lazy loading - data fetched on demand

- **Filters & Search**: Added filtering to Portfolio screen
  - Search by Scheme Name
  - Filter by Investor (dropdown)
  - Filter by AMC (dropdown with full portfolio list)
  - Clear filters button
  - Works with pagination

- **Auto-complete Selects**: Updated Goal and SIP modals
  - Portfolio selection now uses searchable dropdowns with full portfolio list
  - SIP selection in Goals shows portfolio name, amount, start/end dates

- **SIP Table Display**: Fixed portfolio display to show scheme name instead of ID

- **Investor Details**: Added mobile and PAN fields to investor entity
  - Masked display (Mobile: +97858XXXX320, PAN: AVXXX745H)
  - Updated InvestorsTable with new columns
  - Updated InvestorModal with mobile/PAN inputs
  - Stored masked values in IndexedDB

### Data Layer Updates
- Added `getPortfoliosFiltered` and `getFiltered` methods for filter support
- Added `getPortfoliosPaginated` for pagination
- Extended investor model with mobile and pan fields
- Updated user settings to include financeGoals.defaultItemsPerPage
