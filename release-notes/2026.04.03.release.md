# Release Notes - 2026.04.03

## Version 1.7.0

### Features Implemented

#### 1. Module Visibility Settings
- Added ability to enable/disable modules from Settings screen
- Modules organized by category: Productivity, Tools, Finance
- Parent category headers automatically hidden when all sub-modules are disabled
- Default enabled modules: Task Manager, Notes

#### 2. Theme Color Customization
- Added 14 Mantine color options for theme accent color
- Color picker UI in Settings > Appearance section
- Refresh button to apply selected color after page reload
- Default color: Blue (#228be6)

#### 3. Due Time for Tasks
- Added `dueTime` field to Task model
- Users can set due time alongside due date in task forms
- Notifications triggered based on both date AND time
- Tasks with due time: notification only when current time >= due time
- Overdue/upcoming displays show time information

#### 4. Export/Import Data
- Module-wise export functionality (Tasks, Notes)
- Export produces JSON files with timestamp
- Module-wise import with file upload
- Validates JSON format and module compatibility
- Only imports records that don't already exist
