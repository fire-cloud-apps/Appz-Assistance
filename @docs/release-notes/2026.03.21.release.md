# Release Notes - 2026.03.21

## Version 2026.03.21-1

### New Features

#### Notes Module (New)
- **Hierarchical Note-Taking System**: Full implementation of Notes module with folder organization
- **Folder Management**: Create, edit, delete folders with subfolder support (max 2 levels)
- **Note Management**: Create, edit, delete notes with rich text support
- **Rich Text Editor**: Full-featured editor with:
  - Undo/Redo
  - Bold, Italic, Underline, Strikethrough, Clear Formatting, Highlight, Code
  - Headings (H1-H4)
  - Lists (Bullet, Ordered)
  - Blockquote, Code Block, Horizontal Rule
  - Links
  - Text alignment
  - Subscript, Superscript
- **Search**: Full-text search across notes
- **Favorites**: Mark notes as favorites for quick access
- **Trash**: Soft delete with restore capability
- **Tags**: Organize notes with custom tags

### Bug Fixes
- Fixed editor border styling issue
- Fixed rich text content not preserving formatting on reopen
- Added missing delete functionality for notes
