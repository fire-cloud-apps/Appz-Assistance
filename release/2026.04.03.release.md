## Release Notes - 2026.04.03

### Features:
*   **About Modal Implementation:**
    *   Introduced a new "About" modal dialog, triggered by clicking the application logo in the header.
    *   The modal displays essential application information: version, a descriptive application message, and a contact email for feedback.
    *   Enhanced the modal's user interface with a two-column layout, separating the logo/title/tagline from the detailed information, and incorporating a visually centered vertical divider.
    *   Made the application message and feedback email configurable via `src/core/config/appConfig.json` for easier management.
    *   Adjusted spacing and element sizing within the modal for a more compact and aesthetically pleasing presentation.

### Bug Fixes:
*   **Horizontal Scrollbar Resolution:** Addressed and resolved an issue where a horizontal scrollbar would appear in the browser. This was fixed by explicitly setting `overflowX: 'hidden'` on the `AppShell.Main` component in `src/core/services/MainLayout.tsx`.

### Refinements:
*   Improved the overall visual presentation and user experience of the "About" modal.
