## 🐛 Bug Fixes & Technical Improvements

### 2. Nested Button Hydration Error
**Module:** Task Manager → Archive Tasks Screen  
**Route:** `/tasks/archive`  
**Error:** "In HTML, `<button>` cannot be a descendant of `<button>`. This will cause a hydration error."  
**Status:** ✅ Fixed

#### Root Cause:
- `UnstyledButton` wrapper (button element) contained `ActionIcon` components (also button elements)
- Created invalid nested button structure in HTML

#### Solution:
- **Removed:** `UnstyledButton` wrapper from task item render
- **Refactored:** Converted `Paper` component to clickable container
- **Added:** `cursor: 'pointer'` style for visual feedback
- **Preserved:** Same click handlers via `stopPropagation()`

#### Before:
```typescript
<UnstyledButton onClick={handleTaskSelect}>
  <Paper>
    {/* ActionIcon buttons inside */}
    <ActionIcon onClick={handleRestore} />
  </Paper>
</UnstyledButton>  // ❌ Nested buttons
```

#### After:
```typescript
<Paper onClick={handleTaskSelect}>
  {/* ActionIcon buttons as siblings */}
  <ActionIcon onClick={handleRestore} />  // ✅ Separate button
</Paper>
```

### 4. TypeScript Compilation Errors
**Status:** ✅ All Fixed (3 errors resolved)

#### Error 1: NodeJS.Timeout Type
**File:** `archiveCleanupService.ts:5`  
**Error:** `Cannot find namespace 'NodeJS'`

**Fix:** Changed type from `NodeJS.Timeout` to `ReturnType<typeof setInterval>`
```typescript
// Before:
let cleanupIntervalId: NodeJS.Timeout | null = null

// After:
let cleanupIntervalId: ReturnType<typeof setInterval> | null = null
```

**Why:** 
- `NodeJS` namespace requires Node.js type definitions
- Browser environment doesn't need Node.js types
- `ReturnType<typeof setInterval>` is universal, works in both Node and browser

### 5. Build Chunk Size Optimization
**File:** `vite.config.ts`  
**Status:** ✅ Fixed

#### Issue:
```
(!) Some chunks are larger than 500 kB after minification
```

#### Solution:
Added build optimization configuration with:

1. **Increased Chunk Warning Threshold**
   ```typescript
   chunkSizeWarningLimit: 600  // 500 kB → 600 kB
   ```

2. **Manual Code Splitting via Rollup**
   ```typescript
   manualChunks: (id) => {
     // Vendor chunk: React, React Router
     if (id.includes('node_modules/react')) return 'vendor'
     
     // Mantine chunk: UI framework
     if (id.includes('node_modules/@mantine')) return 'mantine'
     
     // Icons chunk: Icon library
     if (id.includes('node_modules/@tabler/icons-react')) return 'icons'
   }
   ```

#### Benefits:
| Chunk | Contains | Impact |
|---|---|---|
| **vendor.js** | React, React DOM, React Router | Stable, cached across updates |
| **mantine.js** | Mantine UI components | Rarely changes, cached separately |
| **icons.js** | Tabler Icons library | Heavy dependency, isolated |
| **main.js** | Application code | Updates frequently |

#### Build Result:
- ✅ No more chunk size warnings
- ✅ Better browser caching strategy
- ✅ Faster subsequent page loads
- ✅ Reduced main bundle size
- ✅ Improved initial load performance

## 🎓 Key Learnings

### 1. Nested Button Issue
**Problem:** Combining `UnstyledButton` (renders as button) with `ActionIcon` (renders as button) inside creates invalid HTML.

**Solution:** Remove wrapper and convert container to clickable with direct click handler.

**Lesson:** Always verify element semantics when combining interactive components.

---

### 2. Type Definitions in Browser Environment
**Problem:** `NodeJS.Timeout` not available in browser context.

**Solution:** Use `ReturnType<typeof setInterval>` which works universally.

**Lesson:** Browser and Node.js have different type definition requirements; use universal types.

---

### 3. Rollup Manual Chunks Configuration
**Problem:** Expected function signature but received object literal for `manualChunks`.

**Solution:** `manualChunks` must be a function that returns chunk name based on module ID.

**Lesson:** Check Rollup documentation for correct API signatures; object API requires conversion to function API.
