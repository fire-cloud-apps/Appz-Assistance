# AppZ Release Notes

**Release Date:** March 17, 2026  
**Version:** 1.4.0  
**Build:** 2026.03.17-2

---

## Overview

This release focuses on modernizing the application stack by upgrading to **Mantine v8** and updating all core dependencies to their latest versions. These upgrades bring improved performance, better security, and access to the latest features.

---

## Major Changes

### Mantine Framework Upgrade (v7 → v8)

The entire UI framework has been upgraded to Mantine v8.3.18:

| Package | Previous | New |
|---------|----------|-----|
| `@mantine/core` | 7.17.8 | 8.3.18 |
| `@mantine/dates` | 7.17.8 | 8.3.18 |
| `@mantine/hooks` | 7.17.8 | 8.3.18 |

**Breaking Changes Addressed:**
- Updated `DateInput` component to use string-based value format instead of Date objects
- Changed `onChange` handler to accept string values directly with `valueFormat` prop
