## Highlights
- Implemented autosave for Notes module
- Visual status indicator shows save state in real-time
- Automatic save on content change and component unmount

## Features

### 1. Autosave Hook
**New hook:** `useDebouncedAutosave`
- Debounced save with 2 second delay (configurable)
- Saves automatically when user stops typing
- Saves on component unmount (cleanup)
- Returns: isSaving, isDirty, lastSaved, saveNow

### 2. Notes Editor Integration
**Route:** `/notes/editor/:id`

**Changes:**
- Connected autosave hook to editor screen
- Status indicator: "Saving...", "Unsaved changes", "Saved X ago"
- Visual feedback: Blue=saving, Orange=unsaved, Gray=saved
- Manual save button with loading state
