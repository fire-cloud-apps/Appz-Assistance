# AppZ Release Notes - 2026.03.23

**Version:** 1.4.0
**Build:** 2026.03.23-1
**Focus:** Task Recurrence & Notifications

## Highlights
- Fixed recurring task creation - Repeat feature now works when creating new tasks
- Added Notifications screen for viewing and managing all in-app notifications
- Fixed archive functionality for recurring tasks
- Theme-aligned hover states for notification lists

## Bug Fixes

### 1. Repeat Task Creation
**Issue:** Repeat settings were not saved when creating new tasks (only worked during edit)

**Fix:** Updated `useCreateTask` hook to include `isRecurring`, `recurrencePattern`, and `recurrenceEndDate` fields

### 2. Recurring Task Archive
**Issue:** Tasks with Repeat enabled could not be archived

**Fix:** Added `recurrencePattern` field to IndexedDB schema (version 5)

### 3. Notifications Route 404
**Issue:** "View All" button threw 404 error - route '/notifications' did not exist

**Fix:** Created NotificationsScreen component and added route

## Added
