## Overview

This release introduces **browser-based due date notifications**, **configurable items per page**, and multiple **UI enhancements** to the Task Manager module. The Calendar module has been removed as per requirements.

---

## New Features

### 1. Due Date Notifications (Browser Notifications)

**Description:** Browser-based push notifications for tasks reaching their due date.

**Configuration:**
- Location: Settings → Due Date Notifications
- Enable/Disable toggle
- Configurable check interval (1-60 minutes)
- Default: Disabled, 1 minute interval

**How It Works:**
- System checks for tasks with due date = today
- Skips completed, cancelled, and already-notified tasks
- Shows browser notification: "Task Due Today!" with task title
- Stores notified task IDs to prevent duplicate notifications
- Notifications auto-close after 5 seconds

**Files Modified:**

### 2. Configurable Items Per Page

**Description:** Users can configure how many items display per page in Task Manager views.

**Configuration:**
- Location: Settings → Task Manager → Default Items Per Page
- Range: 1-50 items
- Default: 5 items

**Screens Affected:**
- `/tasks/all` - All Tasks screen (paged listing)
- `/tasks/groups` - Group Tasks screen (grouped by priority/status)

### 4. Group Tasks - Collapsed by Default

**Change:** All groups now start in collapsed state (not expanded).

**Applies To:**
- Priority Group (Critical, High, Medium, Low, Cancelled)
- Status Group (In Progress, Pending, Completed, Cancelled)

**Benefit:** Reduces initial page clutter and improves perceived performance.

---

### 5. Group Tasks - Limited Items Per Group

**Change:** Each group displays only top 5 items by default.

**Behavior:**
- "Load More" button appears when group has more than 5 items
- Each click loads 5 additional items
- Prevents overwhelming users with long lists

---

### 6. Cancelled Tasks in Priority Group

**Change:** Added Cancelled category under Priority Group view.

**Behavior:**
- Cancelled tasks appear as a separate group alongside Critical, High, Medium, Low
- Active tasks exclude cancelled tasks to avoid duplication
- Red color theme for Cancelled group
- Subtitle: "All cancelled tasks"

---

### 7. Group Tasks - Color & Readability

**Changes:**
- Pending status color changed from `gray` to `blue` (better readability)
- Enhanced group descriptions with contextual subtitles:
  - Critical: "Urgent priority tasks"
  - High: "Important priority tasks"
  - Medium: "Normal priority tasks"
  - Low: "Routine priority tasks"
  - In Progress: "Tasks currently being worked on"
  - Pending: "Tasks waiting to be started"
  - Completed: "Successfully finished tasks"
  - Cancelled: "Tasks that were cancelled"
