# AppZ Release Notes

**Release Date:** March 21, 2026

## Overview

This release focuses on **navigation improvements** and **recurrence task visibility**. All navigation now behaves like a browser back button, returning users to the page they originated from. Recurrence indicators are now consistently displayed across all task views with a unified pink color theme.

---

## 🎯 Key Features

### 1. Repeat Task Indicator - Complete Implementation

**Problem:** Repeat task functionality existed in Task Add/Edit forms, but there was no visual indication in task listings to distinguish recurring tasks from one-time tasks.

**Solution:** Added repeat indicators to all task views with consistent pink styling.

| Screen | Status | Implementation |
|--------|--------|----------------|
| Task Add (`/tasks/create`) | ✅ Existing | Recurrence picker with pattern selection |
| Task Edit (`/tasks/edit/:id`) | ✅ Existing | Recurrence picker loads existing pattern |
| All Tasks (`/tasks/all`) | ✅ Existing | "Repeats" badge with pink icon |
| Task Card Component | ✅ Existing | Pink repeat icon (expanded/collapsed) |
| **Task Dashboard List View** | 🔧 **NEW** | **"Repeat" column with pink indicator** |
| Task Detail Screen | ✅ Updated | Pink recurrence display |

**Visual Design:**
- Icon: `<IconRepeat>` (16px)
- Color: **Pink** (Mantine pink theme)
- Text: "Yes" for recurring, "No" for one-time tasks
- Badge: Pink background for recurring tasks

---

### 2. Navigation Fixes - Browser Back Behavior

**Problem:** After opening a task from any list view (All Tasks, Group Tasks, Archive, Kanban Board), clicking the back button always redirected to `/tasks/dashboard` instead of returning to the originating page.

**Solution:** Changed all navigation calls to use `navigate(-1)` which mimics the browser back button behavior.

#### Scenarios Fixed

| User Action | Before | After |
|-------------|--------|-------|
| Open task from **All Tasks** → Click Back | `/tasks/dashboard` | ✅ **All Tasks** |
| Open task from **Group Tasks** → Click Back | `/tasks/dashboard` | ✅ **Group Tasks** |
| Open task from **Archive Tasks** → Click Back | `/tasks/dashboard` | ✅ **Archive Tasks** |
| Open task from **Kanban Board** → Click Back | `/tasks/dashboard` | ✅ **Kanban Board** |
| Delete task from detail page | `/tasks/dashboard` | ✅ **Previous page** |
| Archive task from detail page | `/tasks/dashboard` | ✅ **Previous page** |

#### Files Modified

| File | Change |
|------|--------|
| `TaskDetailScreen.tsx` | Back button: `navigate(-1)` |
| `DeleteConfirmationModal.tsx` | Delete action: `navigate(-1)` |
| `ArchiveConfirmationModal.tsx` | Archive action: `navigate(-1)` |

---

### 3. Invalid Route Fix

**Problem:** Archive Tasks screen used invalid route `/task/new` for creating new tasks.

**Solution:** Updated to correct route `/tasks/create`.

**Files Modified:**
- `TaskArchiveScreen.tsx` (lines 151, 155)
  - `handleNewTask()` → `navigate('/tasks/create')`
  - `handleEmptyStateCreate()` → `navigate('/tasks/create')`
