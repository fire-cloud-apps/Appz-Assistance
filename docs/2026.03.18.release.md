# AppZ - Release Notes

**Release Date:** March 18, 2026  
**Version:** 1.0.10  
**Build:** 2026.03.18-7

---

##  Overview

This release focuses on enhancing **text formatting capabilities** for task descriptions and activity logs, improving **mobile user experience** with FAB buttons, and fixing **task sorting logic** in the All Tasks view.

---

##  What's New

### 1. Formatted Text Support for Task Descriptions

Task descriptions now fully support formatted text including:
- **Tab characters** - Press Tab to insert actual tab characters for indentation
- **Multi-line text** - Preserved line breaks and spacing
- **Code-friendly input** - Spell check disabled for code snippets
- **Auto-resizing** - Textarea expands from 8 to 15 rows based on content

**Affected Screens:**
- Create Task (`/tasks/create`)
- Edit Task (`/tasks/edit/:id`)
- Quick Create Modal (FAB button)
- Task Detail view

---

### 2. Activity Log Enhancement

Activity logs now support the same formatted text capabilities:
- Larger textarea fields (4-8 rows)
- Tab key support for activity and notes fields
- Formatted display preserving whitespace and alignment

**Location:** Task Detail screen → Activity Log section

---

### 3. Mobile FAB Button for Group Tasks

Added Floating Action Button to the Group Tasks screen:
- Fixed position at bottom-right corner
- Visible only on mobile devices (screen width < 768px)
- Quick access to create new tasks
- Tooltip label "New Task"

**URL:** `/tasks/groups`

---

### 4. All Tasks Screen Improvements

#### Smart Task Sorting
Tasks are now sorted with the following priority:
1. **Non-completed tasks** sorted by due date (earliest first)
2. **Tasks without due dates** appear after dated tasks
3. **Completed tasks** always listed at the end

#### Timestamp Formatting
The "Updated" field now displays in readable format:
- **Format:** `YYYY-MM-DD HH:mm:ss`
- **Example:** `2026-03-18 13:27:21`

**URL:** `/tasks/all`

### CSS Changes

Added `.task-description` class for preserving text formatting:
```css
.task-description {
  white-space: pre-wrap;
  word-wrap: break-word;
  margin: 0;
  padding: 0;
  background: transparent;
  border: none;
}
```

### Mantine CSS Import Order

Fixed CSS import order in `index.css`:
1. `baseline.css` – CSS reset
2. `default-css-variables.css` – Theme variables
3. `global.css` – Global Mantine classes
4. `styles.css` – Component styles
5. `dates/styles.css` – Dates module styles
