# AppZ - Release Notes

**Release Date:** March 18, 2026  
**Version:** 1.0.13  
**Build:** 2026.03.18-15

---

## Overview

This release adds a **Kanban Board** with **touch-optimized drag-and-drop**, improves **All Tasks** pagination stability, enhances Kanban cards with descriptions and subtask counts, and includes a **Kanban build fix**.

---

## What's New

### 1. Kanban Board Screen (Task Manager)
- New screen with status columns: Pending, In Progress, Completed, Cancelled
- Route: `/tasks/kanban`
- Added to Task Manager navigation
- Parent tasks only (consistent with other task views)

### 2. Touch-Optimized Drag and Drop
- Implemented with `@dnd-kit`
- Drag handle to prevent accidental drags on tap
- Drag overlay and smoother drop animation
- Auto-scroll near horizontal edges while dragging
- Drop updates task status by column

### 3. Kanban Card Enhancements
- Short description preview (line-clamped)
- Subtask count badge
- Status and priority badges

### 4. All Tasks Pagination (Lazy Page Loading)
- Paged repository fetch to load only visible page
- Prev/Next pagination retained
- Stabilized total count during fast clicks
- Disabled paging while loading to prevent glitches

### 5. Kanban Build Fixes
- Removed unused React import to satisfy `noUnusedLocals`
- Safe pointer coordinate handling for drag auto-scroll (`Event`/`TouchEvent`)
